Gida · Fitxategiak

Nola esportatu DXF bat laser ebaketarako SolidWorks, Fusion, Inventor, FreeCAD, AutoCAD eta Illustrator edo Inkscape programetatik

Laser ebaketarako DXF bat esportatzeko ez da programa jakin bat behar, baina bakoitzak leku desberdinean ezkutatzen du aukera. Hemen duzu programa bakoitzeko menu-bidea, haren dokumentazioan egiaztatua, eta fitxategia igo aurretik zer berrikusi.

Eskatu aurrekontua Gida guztiak

Esportatu aurretik, edozein programatan

  1. 01Pieza laua, 1:1 eskalan eta mm-tanEsportatu piezaren aurpegi laua edo haren garapena, ez perspektibako ikuspegi bat.
  2. 02Pieza bat fitxategi bakoitzekoKopuruak formularioan adierazten dira, ez pieza kopiatuz.
  3. 03Ebaketa-geometria bakarrikKotarik, markorik, kajetinik eta eraikuntza-lerrorik gabe.
  4. 04Kurba sinpleakProgramak aukera ematen badu, bihurtu splineak polilerro edo arku.
  5. 05DXF ASCIIAukera badago, aukeratu ASCII bitarraren ordez.

Fitxategia irekitzean zerbaitek huts egiten badu, DXFko akatsen gidak azaltzen du nola aurkitu eta zuzendu.

Nola esportatu DXF bat SolidWorksetik

SolidWorksek bi bide ditu xafla-pieza baterako, bere blog teknikoaren arabera:

  1. Aurpegi lautik. Pieza zabalduta dagoela, egin klik eskuineko botoiarekin aurpegiaren gainean, eta Export to DXF/DWG. Ikuspegia aurpegiak berak definitzen du.
  2. Garapenetik. Egin klik eskuineko botoiarekin eragiketa-kudeatzaileko Flat-Pattern eragiketaren gainean. Irteera-koadroan, aukeratu Sheet metal esportatzea eta, ebaketarako, geometria bakarrik.
  3. File > Save As > DXF erabilita. Edozein pieza laurako balio du, baina piezarekiko normala den ikuspegi bat aukeratu behar duzu.

Gordetzean, SolidWorksek garbiketa-tresna bat irekitzen du aurrebistarekin: erabili ebakitzen ez diren entitateak kentzeko.

Nola esportatu DXF bat Fusionetik

  • Krokis batetik. Sortu krokis bat piezaren goiko aurpegian eta amaitu. Nabigatzailean, egin klik eskuineko botoiarekin krokisaren gainean eta gorde DXF gisa. Autodeskek metodo hau gomendatzen du File > Export aukeraren aurrean; haren blogaren arabera, azken hori pieza oso sinpleetan bakarrik dabil ondo.
  • Xaflaren garapenetik. Pieza xaflan dagoela, sortu garapena (Create Flat Pattern) eta erabili Export Flat Pattern as DXF. Markatu splineak polilerro bihurtzeko aukera.
  • Doako bertsioa. SendCutSenden arabera, doako bertsioak ez du DXFrik esportatzen uzten File menutik. Alternatiba garapena da: egin klik eskuineko botoiarekin haren gainean nabigatzailean, eta gorde DXF gisa.

Fusionetik esportatutako garapenak tolestura-lerroak ditu beti. Abisatu oharretan, ebaki ez daitezen.

Nola esportatu DXF bat Inventorretik

  1. Gorputz bakarreko xafla-pieza batean: Sheet Metal fitxa > Flat Pattern panela > Create Flat Pattern.
  2. Nabigatzailean, egin klik eskuineko botoiarekin Flat Pattern nodoaren gainean > Save Copy As.
  3. Save as type eremuan, aukeratu DXF eta gorde.
  4. Garapena esportatzeko aukeren koadroan, aukeratu DXF bertsioa, itzali geruzen fitxan ebaketakoak ez direnak (adibidez, tolestura-lerroak) eta, geometriaren fitxan, sinplifikatu splineak eta bateratu ingeradak polilerrotan, zure lan-fluxuak hala eskatzen badu.

Aurpegi lau bakar baterako, Inventorrek Export Face As du aurpegiaren laster-menuan, hori ere DXF edo DWG formatura.

Nola esportatu DXF bat FreeCADetik

  • Xafla-pieza. Instalatu SheetMetal lan-mahaia Tools > Addon manager menutik. Hautatu erreferentziako aurpegia eta sakatu Unfold. Panelean, doitu zure materialaren K faktorea, markatu Generate projection sketch eta esportatu garapena DXFra panel horretatik bertatik.
  • Pieza laua edo krokisa. Hautatu objektua eta erabili File > Export, Autodesk DXF 2D (*.dxf) motarekin. Draft moduluaren esportatzailea da.

Nola gorde DXF bat AutoCADetik

  1. Utzi pieza bakarrik eredu-espazioan, INSUNITS 4an (milimetroak) dagoela.
  2. Garbitu OVERKILL aginduarekin eta lotu ingeradak JOIN aginduarekin.
  3. SAVEAS (Gorde honela) eta aukeratu DXF fitxategi-mota bat.
  4. Gordetzeko koadroan, Tools > Options aukerak DXF aukerak irekitzen ditu: ASCII edo bitar formatua, hautatutako objektuak bakarrik gordetzen dituzun, eta zehaztasun-hamartarrak.

Nola esportatu DXF bat Illustratorretik edo Inkscapetik

Illustrator

  1. Bihurtu testua ingerada (Type > Create Outlines).
  2. File > Export > Export As eta aukeratu AutoCAD Interchange File (DXF).
  3. Aukeretan, jarri eskala 1 milimetro = 1 unitate. Markatu Outline Text testuren bat geratzen bada, eta Export Selected Art Only hautatutakoa bakarrik nahi baduzu.

Logotipoa beste tamaina batean marraztu baduzu, eskalatu bere benetako neurrira esportatu aurretik. Adoberen foroan badira kasuak non DXF aukera ez den agertzen lan-mahai oso handiekin.

Inkscape

  1. Bihurtu testuak eta formak bide: Path > Object to Path. Inkscaperen DXF esportatzaileak bideak, laukizuzenak eta klonak baino ez ditu onartzen.
  2. File > Save As eta aukeratu Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf).
  3. Aukeretan, kendu dokumentuaren unitatea erabiltzeko marka eta aukeratu mm oinarrizko unitate gisa, edo landu dokumentua mm-tan hasieratik. Zure helburuko programak kurbak irakurtzen ez baditu, aktibatu Flatten Béziers.

Pieza tolestuko bada: esportatu garapena

Xafla laua ebakitzen dugu; ez dugu tolesten. Pieza gero tolestuko bada, zure tailerrean edo beste hornitzaile batenean, bidali tolestuko duenaren erradioarekin eta K faktorearekin kalkulatutako garapen laua. Beste balio batzuekin kalkulatutako garapen batek beste neurri batzuk ditu behin tolestuta.

Tolestura-lerroak ez dira ebakitzen. Jarri beste geruza batean edo ezabatu, eta abisatu oharretan.

Prest duzunean, igo DXFa formulariora: pieza, haren neurriak eta abisuak berehala ikusiko dituzu, eta aurrekontua 24 ordu baliodunetan bidaliko dizugu.

Ohiko galderak

STEPa bidal dezaket DXFaren ordez?+

Bai, onartzen dugu. DXFak abantaila bat du: formularioak pieza eta haren neurriak erakusten dizkizu igotzean.

Tolestura-lerroak esportatu behar ditut?+

Ez dira behar ebakitzeko. Zure programak sartzen baditu, utzi beste geruza batean eta abisatu oharretan.

Zer DXF bertsio aukeratu?+

ASCII formatuko edozein DXF. Formularioak R12tik 2018ra arteko bertsioak irakurtzen ditu nabigatzailean; zure fitxategia beste batekoa bada, guk berrikusiko dugu.

Illustratorreko nire DXFa beste tamaina batekin ateratzen da. Zer egin?+

Berrikusi esportazio-eskala: 1 milimetro = 1 unitate. Igotzean, egiaztatu formularioan neurri osoa.
