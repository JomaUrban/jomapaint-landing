# Cortelaser · vista previa en paint.joma.es/cortelaser/

Copia **generada** de la web de Cortelaser (corte láser de chapa), para enseñarla al equipo.
No se edita aquí: el código fuente es el repositorio `cortelaser-web`
(`python3 src/build.py --base https://paint.joma.es/cortelaser/`). Todas las páginas llevan
`noindex, nofollow` y no están en el sitemap de JomaPaint.

Las solicitudes del formulario van a `/cortelaser/api/solicitud` → contenedor `cortelaser-api`
(ver docker-compose.yml) → iniciativa en Odoo asignada a Igor Rodríguez, con aviso a Igor, Marimar y Jox.
