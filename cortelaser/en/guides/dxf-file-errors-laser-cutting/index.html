DXF errors that hold up an order, and how to fix them

An error in a DXF file for laser cutting usually stops the order before it reaches the machine. These are the faults we see most, how to find them in AutoCAD, QCAD or LibreCAD and how to have them fixed before you send.

Which DXF file errors hold up a laser cutting order?

The machine cuts the geometry exactly as it is in the file. It does not interpret dimensions or notes, and it does not guess what you meant to draw. These are the typical errors in a DXF file for laser cutting, what they cause and the quick way to fix them:

Our own summary based on the Autodesk, QCAD and LibreCAD help and SendCutSend's file guidelines (sources at the end).

Open outlines and duplicate lines

Open outlines

Every outline has to start and end at the same point. A gap of a hundredth of a millimetre is invisible on screen, but the cutting program cannot tell which side is the part and which side is scrap.

In AutoCAD, the JOIN command joins objects into one. According to the Autodesk help, lines have to touch end to end or be collinear; otherwise JOIN ignores them. If the outline still won't close after JOIN, there is a real gap: zoom in and redraw the segment.

A simple check: select the outline. If it is a single closed polyline, it is fine. If loose segments are selected, check the joints.

Duplicate or overlapping lines

They appear when you copy and paste, merge drawings or export from 3D. Two lines on top of each other make the head pass twice: more time, more heat and a worse edge. SendCutSend, for example, automatically rejects 2D files with duplicate paths.

In AutoCAD, OVERKILL removes duplicate or overlapping lines, arcs and polylines, and combines those that partly overlap. In QCAD, Detect Duplicates (shortcut MD) finds exact duplicates, but not partial overlaps; for zero-length segments there is Detect Zero-Length Entities (MZ).

Scale, units and paper space

Draw the part at 1:1 scale and in millimetres. Written dimensions don't count: the machine uses the geometry.

A DXF stores the drawing unit in its header. In AutoCAD it is the INSUNITS variable: 0 is "unitless", 1 is inches and 4 is millimetres. If your file is in inches, everything comes out multiplied or divided by 25.4. If you drew in centimetres, by 10.

In QCAD you can change the drawing unit with Edit > Convert Drawing Unit (shortcut CU), which scales all the geometry. In any program, the definitive test is to measure the whole part before exporting.

Another classic mistake: exporting from a layout (paper space). The DXF may come out at the viewport scale and with the frame and title block inside. Always export from model space, with the part on its own.

Text, blocks and splines

  • Text. "Live" text is a reference to a font, not an outline. Convert it to geometry. In AutoCAD, TXTEXP (from the Express Tools) explodes text into geometry. In QCAD, Explode (shortcut XP) turns text into polylines. LibreCAD has Explode Text into Letters (shortcut xt) and Explode (xp). Then check that the letters are left as closed outlines.
  • Islands. The centre of an O, an A or a B drops out when cut. If you want to keep it, tie the island in with bridges or use a stencil typeface. We cover this in micro-joints and bridges.
  • Blocks. A block reference (INSERT) is "packaged" geometry. Explode it (EXPLODE in AutoCAD, Explode in QCAD and LibreCAD) so it becomes ordinary lines, arcs and polylines.
  • Splines. Some exports turn curves into splines with many points. Autodesk explains that, when a spline is converted to a polyline, the curve is replaced by straight segments with a precision of 0 to 99 %. In QCAD, Explode turns splines into polylines with tangent arcs. If you can, use arcs.

Dimensions, frames and several parts in the same file

A manufacturing drawing and a cutting file are not the same thing. The cutting file contains only the cut line.

Dimensions as dimension entities can be ignored. The problem is dimensions, arrows, frames or title blocks that have already been exploded into lines: to the machine they are geometry and would be cut. Delete them or keep them on a separate PDF drawing.

Put one part per file. If you upload five parts in one DXF, we don't know how many of each you want, or whether you nested them on purpose. Quantities go in the form: one line per part.

Tip Bend lines, centre lines or references go on another layer, and you mention it in the notes so they are not cut. We don't bend: we cut the flat sheet.

Files that don't work as cutting files

  • Binary DXF. Save it as ASCII DXF. In AutoCAD, the DXF options box in Save As lets you choose ASCII or binary.
  • DXF with 3D faces. When exporting from a 3D program without switching to a flat view, the file may contain stray faces or surfaces. SendCutSend lists this among the most common export errors.
  • STL, photos or images. A mesh or an image has no exact outlines. They are useful as a reference, but to manufacture we need a DXF, a STEP or a dimensioned PDF.
  • 0 × 0 file. If the file is empty when opened or measures zero, the part was not selected when exporting. Export again with the part selected.

What the form detects when you upload a DXF

When you upload a DXF to the quote form, your browser analyses it on the spot, without sending it yet. It shows you the part drawn, its dimensions and the cut length, and warns you if it finds:

  • Open outlines, marked in the preview.
  • Several parts in the same file.
  • Text, dimensions, unexploded blocks or splines.
  • A file in inches, centimetres or metres: it converts it to millimetres and tells you.
  • A binary DXF or a file with no geometry in model space.
  • Holes that are small for the material and thickness you choose.

It does not detect everything. Duplicate lines, for example, are not always visible in the preview. That is why we review every file by hand before sending you the quote within 24 working hours.

Checklist before sending the file

  1. Part at 1:1 scale and in millimetres, overall size checked.
  2. Exported from model space.
  3. Closed outlines, with no duplicates or zero-length segments.
  4. Text converted to outlines and blocks exploded.
  5. No dimensions, frames or title block within the geometry.
  6. One part per file, in ASCII DXF.
  7. Holes above the minimum for the thickness: see the minimum hole table.

With that done, upload your DXF and request a quote. If you export from a 3D program, follow the export guide by program.

Frequently asked questions

Will you close an open outline for me?+

If the gap is obvious, we close it and tell you. If it is not clear what you meant to draw, we ask before quoting.

Can I send the dimensioned drawing in the same DXF?+

Better not. Send the DXF with the geometry only and, if you like, a separate dimensioned PDF.

Which DXF version should I use?+

A DXF in ASCII format. If your program offers binary, change the option to ASCII.

How do I know if the file is in millimetres?+

Measure the whole part in your CAD before exporting. When you upload the DXF, the form shows you the dimensions it has read.
