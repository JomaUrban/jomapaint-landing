How to export a DXF for laser cutting from SolidWorks, Fusion, Inventor, FreeCAD, AutoCAD and Illustrator or Inkscape

You don't need any particular program to export a DXF for laser cutting, but each one hides the option in a different place. Here is the menu path for each program, checked against its documentation, and what to review before uploading the file.

Before exporting, in any program

  1. 01Flat part, at 1:1 and in mmExport the flat face of the part or its flat pattern, not a perspective view.
  2. 02One part per fileQuantities are entered in the form, not by copying the part.
  3. 03Cutting geometry onlyNo dimensions, frames, title block or construction lines.
  4. 04Simple curvesIf the program offers it, convert splines into polylines or arcs.
  5. 05ASCII DXFIf there is an option, choose ASCII rather than binary.

If something goes wrong when opening the file, the DXF errors guide explains how to find and fix it.

How to export a DXF from SolidWorks

SolidWorks has two routes for a sheet metal part, according to its own technical blog:

  1. From the flat face. With the part flattened, right-click the face and choose Export to DXF/DWG. The view is defined by the face itself.
  2. From the flat pattern. Right-click the Flat-Pattern feature in the FeatureManager tree. In the output box choose to export Sheet metal and, for cutting, the geometry only.
  3. With File > Save As > DXF. This works for any flat part, but you have to choose a view normal to the part.

When saving, SolidWorks opens a clean-up tool with a preview: use it to remove entities that are not cut.

How to export a DXF from Fusion

  • From a sketch. Create a sketch on the top face of the part and finish it. In the browser, right-click the sketch and save as DXF. Autodesk recommends this method over File > Export, which according to its blog only works well on very simple parts.
  • From the sheet metal flat pattern. With the part in sheet metal, create the flat pattern (Create Flat Pattern) and use Export Flat Pattern as DXF. Tick the option to convert splines into polylines.
  • Free version. According to SendCutSend, the free version does not allow DXF export from the File menu. The alternative is the flat pattern: right-click it in the browser and save as DXF.

The flat pattern exported from Fusion always includes the bend lines. Let us know in the notes so they are not cut.

How to export a DXF from Inventor

  1. In a single-body sheet metal part: Sheet Metal tab > Flat Pattern panel > Create Flat Pattern.
  2. In the browser, right-click the Flat Pattern node > Save Copy As.
  3. In Save as type choose DXF and save.
  4. In the flat pattern export options box choose the DXF version, switch off on the layers tab those that are not for cutting (for example, bend lines) and, on the geometry tab, simplify splines and merge outlines into polylines if your workflow requires it.

For a single flat face, Inventor has Export Face As in the face's context menu, also to DXF or DWG.

How to export a DXF from FreeCAD

  • Sheet metal part. Install the SheetMetal workbench from Tools > Addon manager. Select the reference face and click Unfold. In the panel, set the K-factor for your material, tick Generate projection sketch and export the flat pattern to DXF from that same panel.
  • Flat part or sketch. Select the object and use File > Export, with the type Autodesk DXF 2D (*.dxf). This is the Draft module's exporter.

How to save a DXF from AutoCAD

  1. Leave the part on its own in model space, with INSUNITS set to 4 (millimetres).
  2. Clean up with OVERKILL and join outlines with JOIN.
  3. SAVEAS and choose a DXF file type.
  4. In the save dialog, Tools > Options opens the DXF options: ASCII or binary format, whether to save only the selected objects, and the decimal places of precision.

How to export a DXF from Illustrator or Inkscape

Illustrator

  1. Convert text to outlines (Type > Create Outlines).
  2. File > Export > Export As and choose AutoCAD Interchange File (DXF).
  3. In the options, set the scale to 1 millimetre = 1 unit. Tick Outline Text if any text is left and Export Selected Art Only if you only want what is selected.

If you drew the logo at another size, scale it to its real size before exporting. On the Adobe forum there are cases where the DXF option does not appear with very large artboards.

Inkscape

  1. Convert text and shapes to paths: Path > Object to Path. Inkscape's DXF exporter only supports paths, rectangles and clones.
  2. File > Save As and choose Desktop Cutting Plotter (AutoCAD DXF R14) (*.dxf).
  3. In the options, untick using the document unit and choose mm as the base unit, or work the document in mm from the start. If your target program cannot read curves, enable Flatten Béziers.

If the part is going to be bent: export the flat pattern

We cut flat sheet; we don't bend. If the part is going to be bent afterwards, in your workshop or another supplier's, send the flat pattern calculated with the radius and K-factor of whoever is going to bend it. A flat pattern calculated with other values ends up with different dimensions once bent.

Bend lines are not cut. Put them on another layer or delete them, and let us know in the notes.

When you have it, upload the DXF to the form: you will see the part, its dimensions and the warnings instantly, and we send you the quote within 24 working hours.

Frequently asked questions

Can I send the STEP instead of the DXF?+

Yes, we accept it. The DXF has one advantage: the form shows you the part and its dimensions when you upload it.

Should I export the bend lines?+

They are not needed for cutting. If your program includes them, leave them on another layer and let us know in the notes.

Which DXF version should I choose?+

Any DXF in ASCII format. The form reads versions R12 to 2018 in the browser; if your file is another version, we review it ourselves.

My Illustrator DXF comes out at the wrong size. What should I do?+

Check the export scale: 1 millimetre = 1 unit. When you upload it, check the overall size in the form.
